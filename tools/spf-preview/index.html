A working picture of the spf UI refactor

Every color on this page is resolved live by running the real theme assembler (spf/init.lua) under headless nvim — not hand-copied. Edit any lua/spf/** source and save; this page refreshes within a couple of seconds. Prose (decisions, next steps) is sliced live from colors.md and UI_REFACTOR.md.

Palette

Raw hex from xresources (screen_glasses.*) with baked-in fallbacks — the single source of hex for the theme. Shown here as the fallbacks resolve headless (no xrdb). Syntax hues, then the chrome/UI keys the refactor added.

The UI concept system

Chrome is built from orthogonal, hue-agnostic axes and a small composite vocabulary — a panel hosts controls (textbox, list, view). Colors are swappable; the structure holds.

Panel hosts controls — the composite vocabulary

The orthogonal axes

Text prominence on a surface — label · ghost · accent

Each surface carries the foregrounds legible on it. label = the surface's own fg, ghost = muted secondary, accent = stands-out-via-hue. The ghost contrast bug is visible below where ghost dips toward its background.
